# Gopika A K — Architecture Portfolio

A dark, editorial portfolio for a seventh-semester B.Arch student focused on conservation, material, memory and making.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Replacing content

- Edit project copy and image paths in `data/projects.ts`.
- Edit archive entries in `data/experiments.ts`.
- Add real images under `public/images/` using the prepared folders.
- Biography and philosophy copy live in `app/about/page.tsx` and `app/approach/page.tsx`.

All four current projects and archive notes are clearly identified as placeholder/concept material. Replace them with Gopika's real academic work before final submission.
